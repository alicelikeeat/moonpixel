# 角色美术与照片 / 素材导入

代码：`game/assets/pixel_art.gd`（角色绘制）、`game/assets/asset_importer.gd`（导入）。

## 角色精灵

画布 32×40，脚底在 y=38、水平居中。`PixelArt.character(look, dir, frame, held, child, female)`：

| 部位 | 画法 |
| --- | --- |
| 头 | 12×11，发色覆盖头顶和两侧（女性为长发），两只眼睛、嘴 |
| 手臂与手 | 袖子为衣色，末端 3×3 肤色的手，行走时摆动 |
| 躯干 | 衣色，右侧暗部和腰线 |
| 腿与脚 | 裤色双腿，3 像素高的深色鞋，行走时交替抬起 |
| 描边 | 所有不透明像素外加 1 像素深色轮廓，保证在任何地形上都清楚 |

- `dir`：`down` 正面、`up` 背面、`side` 侧面（向左时水平翻转）。
- `frame`：0 站立、1/2 行走、3 动作（手臂和手持物举起）。
- `held`：`sword` 剑、`bow` 弓、`staff` 法杖（顶端发光球和火花）、`axe` 斧、`pick` 镐、`hoe` 锄、`hammer` 锤、`basket` 篮子、`cane` 手杖。
- 村民按职业拿工具（伐木工斧、采石工镐、农夫锄、建筑工锤、采集者篮子、长者手杖），55 岁后头发变白。
- 儿童是成人精灵按 0.75 缩放。

## 武器与魔法特效

玩家按 Q 切换手持，左键点击地面：

- 剑：两层白色挥砍弧光；
- 弓：带箭羽的箭矢飞行，撞到树或墙消失；
- 法杖：持续的光晕和环绕火花，发射带拖尾的魔法弹，命中处展开光环和火花。

目前只有视觉表现，不造成伤害。

## 照片生成角色

`AssetImporter.photo_to_look(image)`，全部在本机完成：

1. 缩到 64×64，用 YCbCr 肤色规则统计每行每列的肤色像素，取密度 ≥ 35% 峰值的范围作为人脸框（肤色太少时退回画面中上部）。
2. 肤色 = 框内肤色像素均值；发色 = 额头正上方窄带的非肤色均值；衣色 = 下巴下方区域的非肤色均值；裤色取画面底部，若与衣色太接近则用衣色加深。
3. 从原图裁出人脸内区，缩到 10×8 并做色阶量化，正面朝向时画在角色头上。

这是确定性的图像分析，不是生成式模型，不上传任何数据。

## 图片导入为素材

`AssetImporter.pixelize(image, max_side, colors, remove_bg)`：

1. 按最长边缩到 `max_side`（上限 64）。
2. 去背景：取四角平均色，从边缘向内泛洪清除相近颜色。
3. 中位切分求调色板（默认 16 色），每个像素取最近色。

结果保存为存档目录下的 `assets/<id>.png`，作为摆件写入所在区块，随世界一起保存和回收。

## 限制

- 文件：PNG / JPG / WebP / BMP，≤ 20 MB，≤ 8192 像素；GIF 和视频暂不支持。
- 请只导入你有权使用的图片；素材只保存在本机存档中。
