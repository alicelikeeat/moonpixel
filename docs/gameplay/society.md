# NPC 社会模拟 / Society simulation

代码：`game/npc/agent.gd`、`settlement.gd`、`society.gd`。纯逻辑，可无界面运行。

## 村民（Agent）

| 数据 | 说明 |
| --- | --- |
| 身份 | 名、氏族（随父系继承）、性别、出生时间、所属村落、住所 |
| 需求 | `hunger` 饥饿、`energy` 精力、`social` 社交、`health` 健康、`grief` 悲伤 |
| 特质 | `dil` 勤奋、`soc` 外向、`bold` 胆量；子女取父母均值加变异 |
| 关系 | `rel[other_id]` 亲和度 −1..1（`0` 代表玩家）、伴侣、父母、子女 |
| 记忆 | 最近 6 条想法，交谈时展示 |

人生阶段：儿童 < 14 岁（玩耍），成年 14–62（工作），长者 ≥ 62（社交、轻活）。

## 每个村民如何做决定

约每秒一次，按优先级取第一个可执行项：

1. 手里有货 → 送回仓库
2. 饿（> 0.55）→ 去仓库吃饭；仓库空则自己去采集
3. 夜晚或精力耗尽 → 回家睡觉（无家可归则睡在篝火旁）
4. 儿童 → 玩耍
5. 孤独或傍晚 → 去广场找人聊天
6. 按职业工作
7. 闲逛

移动使用村落级 A* 导航网格（96×96 格，随地块变化增量更新）。

## 村落如何分配工作

每 6 秒规划一次：

- **项目**：住房容量不足 → 房屋；每 9 人一块农田；人口 ≥ 14 → 水井；≥ 22 → 路灯广场。最多同时 2 个项目。
- **岗位配额**：有项目才有建筑工；木材 / 石料不足时提高伐木工 / 采石工比例；每块农田 2 名农夫；缺粮时其余人采集。
- **住房**：家人优先住在一起。

建造是逐格进行的：建筑工从仓库领料，走到格子旁，放下一块地块（真实写入世界）。
绝不会把任何人砌在墙里——格子上有人就稍后重试。

## 人口

每游戏小时结算一次：

- **死亡**：基础风险 0.4%/年，55 岁后按 `0.02·e^((age−55)/8)` 增长；饥饿持续会耗尽健康。死后在村落墓地留下墓碑，亲属进入悲伤状态。
- **配对**：聊天提升亲和度（偶尔争吵）；双方单身、成年、异性、非近亲、亲和度 > 0.45 → 结为伴侣并尽量搬到一起。
- **生育**：18–43 岁、有伴侣、村里有余粮、距上次生育 > 1.2 年；孕期 0.7 年。人口接近内存预算给出的上限时生育率下降。
- **迁入**：总人口低于 100 时，流浪者加入人口最少的村落。
- **开拓**：村落 ≥ 34 人且 1.5 年未分村 → 5–9 名青壮年（带伴侣和孩子）出发，在 80–170 格外建立新村落。这也是地图不断扩张的主要动力。

时间尺度：1 游戏年 = 1 个昼夜循环 = 1200 秒（1× 速度）。

## 玩家接口

```gdscript
society.agent_near(world_pos, radius) -> Agent
society.talk(agent_id) -> {name, age, job, mood, line, thoughts, family, ...}
society.gift_food(agent_id)
society.donate(settlement_id, "food" | "wood" | "stone", amount)
signal event(key, text, pos) / agent_born(agent) / agent_died(agent)
```

## 实测（seed 7，120 人，`tools/society_sim.gd`）

10 游戏年：出生 52、死亡 26（年老 9 / 饥饿 11 / 疾病 6）、伴侣 39 对、村落 4 → 7、
房屋 47、农田 21、村民共放置 2965 个地块、已勘测 13305 个区块、进程内存约 28 MB。
墙钟时间约 77 秒（约 160 倍实时）。
