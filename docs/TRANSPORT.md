# 大都市与可驾驶现代交通（v2.7）

本文对应“大都市建设与可驾驶现代交通一体化”任务。基线是 v2.6（`d0391c5`，已发布为 `v2.6`）。所有内容都在开放世界里：没有另一个独立世界，没有装饰车流。

## 1. 状态归属（每样事实只有一个写者）

| 事实 | 唯一所有者 | 怎么改 |
|---|---|---|
| 路、轨道、跑道、滑行道、停机位、码头、站台、停车场 | 开放世界第 1 层的地块（新地块 150–163） | `planWay` → `startWay`（付款）→ 工地逐格施工（`workSites` / `finishSite`） |
| 桥（人行、公路、铁路、高架、开启桥）、隧道、船闸 | `realm.transportBox`（`TransportState`） | 施工时生成；`demolishBridge`、`requestOpening`、法则（归墟）移除 |
| 不再长树的走廊（路、轨道、跑道两侧、建筑门口） | `TransportState.corridor` | 施工、建筑落成时加入；村庄造林只经 `canPlant`，它拒绝走廊 |
| 车辆：位置、高度、朝向、速度、所在层、燃料、磨损、乘客、货物、任务、路径、控制者 | `Vehicle`（`TransportState.vehicles`） | 只由 `vehiclesStep` 推进；驾驶者（玩家或自动驾驶）只设 `Controls` |
| 车站、线路、班次、晚点、票款 | `Stop`、`Line` | `addStop`、`addLine`、`assign`、`linesStep` |
| 货物运输 | `Shipment`；货物在任一时刻只在一处：某个货场、某辆车、或已送达 | `ship`、`exchange`、`arriveAt`、`transferYards`、`deliver` |
| 都市区：建筑、楼层住户、岗位、仓库、资金、市政、人口账本 | `District`（`TransportState.districts`） | `districtDay`、`placeCityBuilding`、`importMetro`、规划器 |
| 跨区通勤的居民 | `Commuter`（每人一条记录，人口仍只算在家所在的楼层） | `commutersStep`、电梯 `ride`、车站 `waitAt` |
| 旅人在车里的位置 | `PlayerState.body`（`vehicle`、`lx`、`ly`、`lz`、`seat`） | `board`、`moveAboard`、`syncAboard`、`leaveVehicle` |

渲染（2D 的 SpriteKit、3D 的 RealityKit）只读这些状态。

## 2. 单位

- 水平：模拟单位，每格 16（与全游戏相同）。一格约 2 米：速度显示 = 格/秒 × 7.2 km/h。
- 高度：格。飞机的 `z` 是离地高度；桥面的 `deckZ` 是桥面离下方地面或水面的高度。
- 层（`level`）：0 地面（包括平交道口、桥下的水面和道路），1 桥面，−1 隧道。桥面只沿自身方向连通，只在两端顺着桥的方向接到地面：高架下的街道和高架上的公路互不相连；船从桥下过，车从桥上过。

## 3. 修建：预览、清障、付款、施工

1. **预览**（`planWay`）：给出路线的每一格、要砍掉的树/灌木/石头和它们产出的木材与石料、需要的桥（每段水面或被跨越的道路一座）和隧道（穿过山崖）、总费用。预览本身不改变世界。
2. **规划规则**：沿已有同类道路最便宜；空地 1；树林 2.2（要砍）；水面要桥（深水更贵）；山崖要隧道；**任何建造物（墙、房屋、机器、别人的地板）都绕开，绝不穿过**；街道与铁路平交，其余交叉用高架；跑道两侧各一格也要清空。
3. **付款**：一次付清，付不起则什么也不扣。付款方可以是背包、城镇仓库或都市区仓库；每笔都写入账本。
4. **施工**：工地按每小时若干格推进，每一格先砍伐（木材、石料交给付款方并记账）再铺设；桥的最后一格完成时桥才可通行。
5. **不再长树**：已铺设的格子、跑道两侧、建筑门口进入走廊，村庄造林在规划和种植两步都会检查。

**AI 选择过河方式**（`crossingOptions` + `chooseCrossing`）：比较绕已有道路、只清障修路、修桥、修隧道、渡轮五种方案；费用 = 材料 + 一年里每天多花的行驶时间。没有可行方案时返回空，车辆显示“无路可走”并等待；网络一变（新路、新桥、桥被拆）就重新规划。

**开启桥**：船请求开桥 → 落下栏杆（`stopping`），之后不准任何车辆上桥 → 只有桥面上没有车、也没有旅人时才开始升起 → 升起后船通过 → 无船时放下 → 恢复通车。桥面上的车在栏杆落下后仍可开下桥。

## 4. 车辆

| 种类 | 方式 | 能源 | 手动操作 | 自动驾驶 |
|---|---|---|---|---|
| 汽车、公交、货车 | 公路 | 燃料 | 转向、油门、刹车、倒挡；离开道路只能慢行，不能下水、穿树、穿墙、穿车 | 沿路线追踪靠右行驶，弯道减速，跟车保持制动距离，准确停站 |
| 普通列车 | 铁路（也可走高铁线） | 燃料 | 牵引、制动（不能离开轨道） | 按线路限速与停车距离运行 |
| 高铁 | 只走高铁线 | 电网（所属都市区的富余电力） | 牵引、制动 | 同上 |
| 客机、货机 | 跑道、滑行道、停机位；空中 | 燃料 | 地面：转向、油门、刹车（低速可原地转向）；空中：横滚转向、俯仰、油门、飞行辅助（定高定向、不低于失速） | 滑行、对准跑道、起飞滑跑、爬升、截获跑道延长线、下滑道、拉平、接地、减速、滑回 |
| 渡轮、客轮、货轮 | 足够深的水，桥下净空足够 | 燃料 | 舵、推进、倒车（低速时侧推器慢转） | 沿航线，目标在后方时先停船转向，靠泊 |

- **信号**：每列车占用它所在的轨道和身后车长的轨道；前方被占用时，列车保护系统按紧急制动距离停车，手动驾驶闯红灯也会被强制制动并记录事件。
- **燃料、电力、维修**：燃料按行驶距离和油门消耗，从所属仓库加注（真实货物“fuel”，由炼油厂用石油炼成）；电力车从电网取电，电网没电时没有牵引；磨损按里程累积，磨损满时抛锚，需在线路端点用构件修理。
- **事故**：汽车高速碰撞记事故；飞机在跑道外接地、下沉过快或冲出跑道即坠毁；船高速触底记搁浅。
- **手动与自动交接**（`setControl` / `handOver`）：只换由谁设定操纵量，位置、速度、高度、乘客、货物、任务都不变；下一步的位移不超过当时速度所能走的距离（测试逐项比较）。
- **车内走动**：旅人在车里时，位置以车的坐标系记录（前后、左右、离地板高度）。车转弯、加速、刹车时人随车动；车内可以走、可以跳，落回车厢地板。驾驶座上的人不走动。只有车停稳（船在泊位、飞机在地面）才能下车。

## 5. 线路、班次与出行

- 线路在两端之间往返，每端每隔 `headway` 秒发一班；到站停车、开门、下客、上客（只上去往前方车站的人）、卸货、装货；按时刻表计算晚点。
- **费用**：通勤者的票款从所在都市区的资金转给线路所属方；每天按车辆数扣线路运营费；都市区修的路每天消耗构件维护（不够时折成资金）。
- **出行规划**（`planTrip`）：从当前位置步行到附近车站，按线路和换乘（步行 10 格内可换乘）求最快路线，给出每段线路、换乘次数和总时间。停运线路、通往交战国家的线路不使用。
- **边境与战争**：线路经过的国家之间处于战争时线路停运（“停运：战争”），车停在站内，乘客不能为去往交战国的车站等车；停战后自动恢复。
- **远近聚合**：离旅人 96 格以内、最近的 40 辆车做完整物理；其余车辆是同一个对象，按所在路段的限速和拥堵沿路线前进（列车仍受信号约束）。靠近、离开、切换视角都不会复制或丢失乘客和货物（测试中列车跨越远近边界时每一步核对“货场 + 车上 + 已送达 = 发出量”）。

## 6. 运输链

农场产粮 → 货车从农场货场运到铁路货场 →（相邻货场直接转运）→ 货运列车 → 对岸铁路货场 → 货车运到城市货场 → 都市区仓库 → 每天按楼层需要分发：地面层直接搬入，4 层以内无电梯时走楼梯，更高的楼层只能由外置电梯送上去 → 居民按营养吃掉。

每一次装车、卸车、转运、入库、送上楼都真实扣减和入账。运输中断时：
- 仓库是满的，但电梯停电，高层照样挨饿（测试：顶层饥饿、一楼不饿）；来电后按电梯真实送达的量逐步恢复。
- 桥断后线路车辆停下等待，新路修通后绕行。

## 7. 都市区

- **建筑用途**：住宅（住宅楼、高层公寓）、商业（商店、写字楼）、工业（工厂、炼油厂、油井）、农业（农场）、物流（仓库）、公共服务（发电厂、自来水厂、污水处理厂、垃圾站、消防站、医院、学校）、混合用途（底商住宅）。每座建筑在世界里有墙、楼板、门（入口）、内部家具、楼梯；三层以上的住宅自动加装外置电梯（从都市区仓库付款）。
- **市政**：每种服务有容量、每日费用和效果——缺电：楼宇断电、电梯停、工厂停产、高铁无牵引；缺水或污水处理：疾病和死亡增加；缺垃圾处理：疾病与不满；无消防：可能失火烧毁建筑（住户迁到空房或离开）；医院降低死亡率；学校提高产出。服务按员工到岗比例发挥作用。
- **人口**：人口 = 各楼层住户之和，只因出生、死亡（按原因）、迁入（必须有来源：同国区域城市，那里减少）、迁出（去往同国区域城市，那里增加）以及都市模式城市并入而改变；账本随时可核对（`ledger.expected == population`）。迁入要求有空房、有岗位（含可通勤到达的外区岗位）、仓库至少三天口粮、有电有水。
- **AI 建设顺序**：每次一个项目——清障（木材归都市区）→ 修路到门口（真实工地）→ 确认市政能承载 → 付款建造 → 入住。缺市政时先建市政。资金或材料不够就等。不会在玩家建造的东西、城镇范围、其他都市区建筑、道路或走廊上建造。
- **并入都市模式城市**（`importMetro`，“更多 → 都市并入开放世界”）：同一块土地上，道路变成街道或高速，建成地块按同类相邻合并成楼栋（最大 6×6），住宅层数为原等级的两倍，每个居民都分到楼层，资金、发电、供水、消防、医院、学校随之迁入；只并入一次；原来按“都市人口挂靠”计入国家的人口改为按都市区计入，不重复计算。并入前先固定存档备份。

## 8. 通勤

跨区通勤者是逐人记录：早 7 点离家（高层先乘外置电梯下楼）→ 步行到车站 → 公交 → 换乘高铁 → 下车步行到工作楼 →（楼上则乘电梯）→ 到岗；晚 17 点反向回家。无路可走时留在原地，第二天再试，并计入“拒载”。区内通勤（同一都市区内）按岗位填充比例汇总计算，不逐人模拟。

## 9. 界面与操作说明

- **出行**（右下角汽车按钮）：附近车辆（驾驶或乘坐）、用背包材料造一辆车、目的地列表、路线（步行、线路、换乘、时间）、“在第一站等车”。
- **驾驶界面**：左上仪表——速度（km/h）、限速、档位、燃料或电网、乘客与货物；飞机加高度、升降速度、航向、飞行阶段；船加舵角与靠泊状态；列车加信号灯。右上：手动/自动驾驶切换、驾驶舱/车外视角、停稳后“下车”。底部：左右转向（按住）、拉杆/推杆（飞机）、飞行辅助（飞机）、前进/倒挡（汽车、飞机、船）、油门或牵引滑杆、刹车（按住）。摇杆在驾驶时也能用：左右转向，向前加油门，向后刹车。乘客模式只显示下一站和停稳后的下车按钮。
- **交通管理**（更多 → 视角与操作 → 交通管理）：选择要修的种类 → 在此设起点 → 走到终点后“在此设终点并预览” → 看砍伐、桥、隧道和费用 → 确认开工（背包付款）。下方列出都市区（人口、住房、岗位、资金、粮食、各项市政覆盖率）、线路（车辆数、班次、载客、平均晚点、运量、停运原因）、车辆（速度、燃料、停驶原因）、瓶颈（拥堵路段、停运线路、晚点线路、满载线路、无车线路、停驶车辆）和累计统计。
- **演示**：启动参数 `--transport-demo` 在旅人附近用同样的规则（规划、付款、砍伐、施工）修一条街（汽车、公交线）、一条高铁线（电站与住户供电）、一条三格宽的跑道（客机），附近有深水时再修码头放渡轮；`--drive-plane` 让旅人直接坐进客机驾驶座。

## 10. 性能（实测，Linux x86_64 发布构建，`V27BenchTests`，不是手机）

| 场景 | 结果 |
|---|---|
| 汽车寻路 156 格（过桥） | 0.45–0.67 ms |
| 规划 156 格铁路（穿林、跨河） | 26–44 ms（一次性，规划时） |
| 200 辆公交全部在远处 | 每 1/30 秒步 0.22–0.30 ms |
| 200 辆公交挤在旅人身边（其中最近 40 辆做物理） | 每 1/30 秒步 4.1 ms（修正前为 27 ms：车与车的碰撞和跟车检查原为两两比较，改为 4×4 格分桶，并设物理上限 40 辆） |
| 29 个车站的出行规划 | 0.035–0.040 ms |
| 并入 841 人、93 座建筑的都市 | 1.6–1.9 ms；一个都市日 1.3–2.3 ms |
| 含 200 辆车的整个社会存档编码 | 29–62 ms，约 300 KB |

真机未测：帧率、GPU 时间、内存、发热、触控手感都没有数据。

## 12. 没有做到的（如实列出）

- **真机**：全部未在真机上运行；帧率、内存、发热、触控手感未测。
- **界面只自动测了汽车**：高铁、飞机、轮船的驾驶在核心测试中逐项验证，界面上的驾驶舱、仪表和按钮只在模拟器里自动测了汽车一种；其余三种的界面操作未经自动测试。
- **3D 模型**是方块拼成的简单造型，驾驶舱内部没有仪表几何（仪表在界面上）；2D 用带朝向的色块表示车辆。
- **道路**：单格宽，靠右行驶通过横向偏移实现，没有多车道、红绿灯和路口让行规则；立交只有直线方向的高架与匝道，没有环形或苜蓿叶匝道；停车场只是地块，没有停车行为。
- **铁路信号**是“列车占用轨道 + 列车保护制动”，没有可见的信号机和道岔对象（道岔由路线选择隐含）。
- **航空**：没有风、没有空中交通管制，机场是跑道、滑行道和停机坪地块，航站楼是车站而不是建筑；货机没有专门的货运线路测试。
- **水运**：船闸只有等待时间，没有水位差；没有拖船；只在码头旁靠泊。
- **战争**：通过关闭边境和线路停运体现，没有轰炸桥梁或拦截车辆。
- **区域层（远方城市）**没有真实车辆，远方贸易仍用区域层自己的估算；本系统只在开放世界内运行。
- **都市区**：区内通勤按比例汇总，不逐人模拟；玩家目前只能经“并入都市”或规划器得到都市区建筑，界面上还没有让玩家手动放置都市区建筑的按钮（核心有 `placeCityBuilding`）；货运与客运共用同一部外置电梯，没有单独的货梯。
- **都市并入**：警察局、公园、地标没有对应的开放世界服务，未迁入；住宅层数按“等级 × 2”换算，是约定而非原城市的真实层数。
