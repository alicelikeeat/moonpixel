# 海洋国家与陆海空战争

《海洋国家与陆海空战争开发任务书》的实现说明：做了什么、代码在哪、怎么验证的、还缺什么。

## 1. 开工核对：可复用的类型与缺口

| 任务书要求 | 已有的（复用） | 新增 |
|---|---|---|
| 国家数量不固定、按 ID 展示 | 区域层 `Civ`（`CivPolity`，国家数量由世界生成和分裂决定） | 无需改动；国土地图和卡片都按国家 ID |
| 世界生成、海岸 | `Generator`、`Civ.survey`（区域的水、深水、山地比例） | 海洋层（`Generator.continental`）、公海、港口位置 |
| 外交、停战 | `CivRelation`（和平 / 交战 / 停战）、同盟、`Annexation` | 使者、附属、具体目标战争 |
| 单位、载具 | `CivUnit`：步兵、装甲、战斗机、航母、重型机兵 `frame`、空天母舰 `sky_carrier` | 变形机甲 `shifter`、女巨人 |
| 战斗 | 远近共用的一套战斗（`CivWar`） | 目标争夺的十倍规则结算（`Diplomacy.swift`） |
| 地图 | `WorldMap`（地形图与标注） | 国土模式 |
| 存档 | `Civ` 的编码（缺字段时取默认值） | 所有新字段同样可缺省 |

## 2. 代码在哪

| 文件 | 内容 |
|---|---|
| `World.swift` → `Generator.continental` | 海洋层：只对新世界（`WorldRecipe.oceans`）生效，出生点 300 格内不变 |
| `Geography.swift` | 公海、港口位置、法定归属 / 实际控制、沿海出生规则、关城挡路的陆路、四种天险 |
| `Diplomacy.swift` | `WarBalance`（全部平衡数值）、使者、附属、目标战争、冻结快照、十倍规则、面板文字 |
| `Logistics.swift` | 船队运量、港口接收量、首批四项科技、瓶颈提示 |
| `Mechs.swift` | 人形机甲涉水、变形机甲两种形态 |
| `Airborne.swift` | 空天母舰投送机甲、女巨人 |
| `Damage.swift` | 方块与物品的材质、耐久、谁能拆什么 |
| `WorldMap.swift` → `paintNations` | 国土模式着色、国界、斜纹、附属外圈、标注 |
| `App/HUDView.swift`、`App/CivPanel.swift` | “地形｜国土”切换；国家卡片“国土与战事” |

## 3. 规则摘要

- **公海**：连在一起的 4 个及以上海区。小于 4 个是湖。
- **港口位置**：挨着公海的陆地区域。
- **法定归属 / 实际控制**：区域记录 `legal`（法定）和 `claim`（它听命于哪座城）；实际控制方 = 那座城现在的主人，攻城后立刻生效；`cede(city:)`（停战割让）才改 `legal`。
- **沿海出生规则**（只对新世界）：每个开局国家分到离它最近、能从陆路走到的无主港口位置；没有就从邻国非城市、非唯一港口的海岸里分；已知地图里没有就向外勘察最多 8 圈。60 个种子、431 个国家全部满足（`GeographyTests`）。
- **使者**：可动员战力 ≥ 对方 3 倍、无交战 / 停战 / 待决使团 / 附属关系时才派；候选按距离、再按“港口 > 关城 > 城市”排序。
- **答复**：抵达时掷一次骰，结果、理由和使团 ID 存档；拒绝率 10%，若对方握有要道（盆地关口或海峡港口）、存粮 ≥ 20 天且首轮兵力 < 十倍则为 20%。
- **目标战争阶段**：集结（1 天）→ 出发 → 抵达（12 天内没有地面部队到场就撤军）→ 争夺（冻结快照，结算一次）→ 占领或撤军 → 停战（8 天内不再宣战，占领的城市随停战割让）。
- **有效战力** = 数量 × 基础战力 × 完好度 × 补给 × 地形 / 训练修正；守城工事只给守备步兵加成；登陆 × 0.75；海运只计港口本轮接收得下的部分。
- **胜率表**：0.5∶1 → 20%，1∶1 → 40%，2∶1 → 65%，5∶1 → 85%，9∶1 → 98%，≥ 10∶1 → 100%；节点之间线性，0.5 以下线性降到 0。低于十倍时取整可能显示 100%，界面改为“约 99%，仍可能撤军”。

## 4. 验证

Linux（Swift 6.0.3，`swift test -c release -Xswiftc -enable-testing`）上全部核心测试通过，新增的测试：

| 测试 | 覆盖任务书条目 |
|---|---|
| `GeographyTests`（12 项） | 公海与湖、港口位置、占领不改国界 / 停战割让才改、沿海规则（固定种子逐国验证 + 60 种子）、只对新世界生效、关城易主开路、三关盆地（有平原入口就不算）、两种海峡、河洲、群岛 |
| `DiplomacyTests`（7 项） | 胜率表与任务书数值样例、3 倍门槛、使者只答复一次（含存读档）、归附纳贡不成环、拒降→目标战争、空中占优无人到场不能占城、10∶1 必胜 / 9.9∶1 可撤军、战报首行与可还原的比值 |
| `LogisticsTests`（2 项） | 只增船舱不增港口到场不变；航母移动后舰载机返航、数量守恒 |
| `MechTests`（3 项） | 坦克与机甲可达区域不同；变形前后损伤连续、变形中不移动不占领、空间不足给原因、读档后只有一台 |
| `AirborneTests`（3 项） | 投送一次只出现一台、落地前不参与争夺、投送中存读档只落地一次；女巨人守城 / 救援分别记功、人数守恒、清障后道路真正通行 |
| `DamageTests`（4 项） | 砍树、敲石、墙上开洞后可通行、材料只给一次、磨损随存档；建设 AI 只清理施工范围、绕开建筑；战争 AI 只打标记目标、停战即停 |

## 5. 还没做 / 没验证

- **没有真机数据**：任务书第 7 节的真机 60 FPS、P95 帧耗时、内存峰值都没有测（没有可用的 iPhone）。
- **玩家驾驶与 AI 接管同一单位**：区域层单位（航母、机甲、空天母舰）和近景可驾驶载具（`Vehicle.swift`）还没有共用 ID；玩家还不能登上航母切换舰载机、驾驶机甲或变形机甲。
- **3D 模型与动作**：变形机甲、女巨人、空天母舰投送都还没有 3D 模型和动画；破坏的木屑 / 火花 / 玻璃碎片等特效没做（核心只返回材质和剩余耐久）。
- **天险原型**：现在是“按真实路线识别”地形里自然出现的海峡、盆地、河洲、群岛；还没有在生成时主动“造”出这些地形，其余六种原型（内海、高原水塔、瀑布台地、长湾双港、环礁泻湖、背山黑土）没做。
- **建设 AI 改线**：破坏规则会拒绝并给出原因，但现有的修路 / 建房规划器还没有调用它来改线。
- **双港之战最终演示**：固定种子、可重放事件记录、同场景演示都还没做。
- **App 层只能靠 CI 编译**：本机（Linux）无法编译 SwiftUI；国土地图和国家卡片的界面需要在 CI 和模拟器上确认。
