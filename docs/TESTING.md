## 未验证事项

- **1.3 真机验证（任务书要求的一小时连续运行、帧时间、内存、发热、卡顿）没有做**：我没有真机。需要在明确型号上安装后记录，建议记录项：机型与系统版本、连续运行时长、HUD 中“实际速度”、设置里的内存读数、是否发热降频、是否闪退。
- **同屏 200–400 名士兵没有压力测试**：当前同屏最多画 50 个人物，其余按建筑计数显示；军团以旗帜、人数和士气条表示。是否能提高到 200–400 需要真机数据决定。
- **录像来自 CI 的 iOS 模拟器**，不代表真机流畅度。
- **建造、城市、战争的界面只在模拟器界面测试里走过一遍主路径**，拖动建造在真实手指操作下的手感没有验证。
- **保存失败重试**：核心层有测试；App 里“保存失败 → 暂停世界 → 重试保存”的流程没有在真正写满的磁盘上验证。
- **远处军团与近处士兵共用同一套军团数据**，因此远近一致；但近处并没有逐个士兵单独结算的精细战斗（任务书要求的“近处按士兵精细模拟”没有做到）。
- **小队共享路径、空间索引的局部避障**没有实现：整支军团共享一条路线，士兵按队形跟随。
- **真机**：没有在任何真实 iPhone 上运行过。触摸、性能、发热、内存警告处理、照片库权限流程都只在模拟器里走过。
- **帧率**：未测量。
- **空间不足**：保存失败的提示和“旧存档保持完好”依赖原子写入，代码路径已实现，但没有在真正写满的磁盘上测试过；测试只覆盖了日志损坏和中断重放。
- **App 层的法则流程**：删除计划、分批执行、日志恢复在核心层有测试；App 层（保存 → 写日志 → 执行 → 清理素材 → 保存 → 删日志）只由模拟器界面测试走通正常路径，没有在 App 里模拟过中途被杀。
- **异步照片任务作废**：切换世界、目标被删除、创世纪后丢弃结果的判断已实现，没有自动化测试。
- **自动容量策略**：决策逻辑有测试；在 App 里按水位自动触发没有实际跑到过（需要把世界写到上限附近）。
- **Vision 人脸识别和人像分割**：模拟器里用合成图片测试，没有用真实照片和真实视频验证效果。
- **特效与天气的观感**：只看过模拟器截图，没有在真机上看过实际动画效果和流畅度。
- **平衡性**：41 种能力的伤害、冷却和研究速度只保证机制正确，没有做过平衡测试；高级能力可以一击清场。
- **“我的世界”式的系统**：只加入了动物、天气、昼夜、农耕、采集、建造道路桥梁、驯养、迷宫、作弊这些通用系统；没有合成与附魔、地下采矿、红石电路、其他维度、逐方块建造和联机。
- **湮灭的摆件统计**需要读取所有已保存的区块文件，地图很大时这一步可能较慢，没有在大存档上测过耗时。
